# Stock Price Prediction with LSTM and GRU

## Project Overview

This project predicts Apple (AAPL) stock closing prices using Deep Learning models implemented with PyTorch.

## Models

- LSTM
- GRU

## Technologies

- Python
- PyTorch
- Pandas
- NumPy
- Matplotlib
- Scikit-Learn

## Evaluation Metrics

- MSE
- RMSE

## Results

Both models were trained on historical Apple stock prices from Yahoo Finance and compared using prediction accuracy metrics.
